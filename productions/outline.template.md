# Outline template (proposed 2026-11, on trial until the owner approves)

Copy to `productions/NN-slug/outline.md` at topic time, fill it in, and get the owner's OK before writing
`script.txt` (science-script-v2 §2d). Times assume the voice's pace (Rudra about 170 words a minute, Neel 147);
`script_check.py` prints each section's start time.

```
TITLE PROMISE: <one line: what the viewer is promised>
TITLE IDEAS:   1) <the proven keyword>  2) <with a number>  3) <in Hinglish>
SPINE: <one question>, or for a list: <escalating axis: distance / size / time / danger>, said in every chapter

HOOK (<=130 words, ~45 s)
  0-10 s   present-tense scene proving the title (<=12 words, no hedge, something the footage can show)
  10-25 s  stakes for Earth / insaan, made tangible (by 15 s)
  25-40 s  2-3 specific teasers (pictures, not themes); the last one = the ending's idea
  bridge   names ch1's first picture

CHAPTER n (60-95 s), starts ~m:ss   [strongest real event near 2:30-3:30 and ~6:00?]
  belief -> person + year + moment -> LEKIN -> payoff
  number = everyday picture
  archive clip / bite id
  bridge: one concrete next picture (not a category, not the last chapter's template)

ENDING (<=45 s): payoff -> callback to the hook scene -> third-person hand-off
PINNED POLL: <options>
```
